# Метки triage

Скиллы говорят о пяти канонических ролях triage. Этот файл сопоставляет роли
с фактическими строками меток в трекере этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                     |
| ------------------------- | --------------------- | -------------------------------------------- |
| `needs-triage`            | `needs-triage`        | Сопровождающему нужно оценить задачу         |
| `needs-info`              | `needs-info`          | Ждём от автора дополнительную информацию     |
| `ready-for-agent`         | `ready-for-agent`     | Полностью описана, готова для агента без человека |
| `ready-for-human`         | `ready-for-human`     | Нужна реализация человеком                   |
| `wontfix`                 | `wontfix`             | Не будем делать                              |

Когда скилл упоминает роль (например, «поставь метку готовности для агента»),
берите строку из столбца «Метка в нашем трекере».

Меняйте столбец «Метка в нашем трекере», если словарь в трекере другой.
