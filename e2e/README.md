# E2E-проверки

Скрипты на Playwright: проходят приложение в настоящем браузере и складывают
скриншоты. Нужен запущенный сервер и база с демо-данными (`npx tsx prisma/seed.ts`).

```bash
npx playwright install chromium        # один раз
AUTH_PASSWORD='ваш-пароль' node e2e/flow.mjs
```

## Переменные

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BASE_URL` | `http://localhost:3000` | адрес запущенного приложения |
| `AUTH_PASSWORD` | — (обязательна) | пароль входа, тот же, что в `.env` |
| `SHOTS_DIR` | `e2e/screenshots` | куда складывать скриншоты |

Пароль и адрес в скриптах не зашиты: без `AUTH_PASSWORD` скрипт сразу
останавливается с подсказкой. Каталог скриншотов в `.gitignore`.

## Скрипты

- `flow.mjs` — объект → муфта → кабели → прямая сварка → документ.
- `cold-start.mjs` — создание с нуля, дубль номера, ручная сварка, защита от повтора.
- `share.mjs` — фото, метки, публичная ссылка, проверка доступа к файлам.
